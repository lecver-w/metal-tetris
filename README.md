# 金属质感俄罗斯方块 (Metal Tetris)

专为安卓手机竖屏打发时间打造的硬核金属质感俄罗斯方块。支持**纯手势操控**、**自动存档**与 **PWA 离线运行**。

---

## 🎮 纯手势操作指南（屏幕任意位置均可滑动）

| 手势动作 | 对应游戏功能 | 震动/体感说明 |
| :--- | :--- | :--- |
| **左右滑动** | 方块水平移动 | 移动时伴随微弱机械步进震感 |
| **轻触点击** | 顺时针旋转方块 | 机械卡扣清脆音效与微震 |
| **向下慢慢拖动** | 软降（加速慢落） | 下落增加奖励分（1分/格） |
| **快速向下一甩 (Flick)** | 硬降（直接砸到底） | 沉重金属钝响与重震感（2分/格） |
| **向上滑动** | 暂存方块 (Hold) | 亦可直接轻点左侧暂存槽 |

---

## 🛠 游戏性设置开关（点击右上角齿轮）

- **辅助落点投影 (Ghost)**：开启后底部显示虚线阴影，极大降低误操作。
- **暂存槽功能 (Hold)**：支持将当前尴尬方块收纳备用。
- **7-Bag 现代发块机制**：开启时保证 7 种块循环出现，不卡手；关闭则为纯真随机。
- **触觉震动反馈 (Haptics)**：适配安卓手机的 Web Vibration 机械震动反馈。
- **金属打击音效 (Sound)**：由 Web Audio API 动态合成，无需任何外挂音频文件。
- **滑动灵敏度调节**：可根据自身指尖手速调节步进步长（像素阈值）。

---

## 💾 全自动存档机制（随时离开随时恢复）

- **自动存档**：支持监听手机切出应用（如来电话、切微信）、锁屏、关闭网页或意外刷新，游戏会自动暂停并将完整棋盘、得分、连击与待落块持久化到手机本地存储。
- **即开即玩**：下次重新打开页面，点击“继续游戏”直接无缝恢复。

---

## 📱 手机如何体验与脱离电脑离线游玩

### 1. 局域网即时体验
1. 确保手机与电脑连接在同一个 Wi-Fi 网络下。
2. 双击运行 `start-server.bat`。
3. 在手机浏览器（推荐 Chrome 或 Edge）中输入控制台显示的网址（如 `http://192.168.1.6:8080`）。

### 2. 脱离电脑 / 离开 Wi-Fi 永久畅玩（PWA 离线安装）
1. 在手机 Chrome 中打开游戏页面。
2. 点击浏览器右上角菜单 `⋮`，选择 **“添加到主屏幕”**（或“安装应用”）。
3. 手机桌面上会生成专属金属方块 App 图标。
4. **只要安装或访问过一次，由于 Service Worker 离线缓存机制，即使电脑关机、手机处于飞行模式/断网状态，点击桌面图标也能全屏秒开畅玩！**
